# My Robot Package

ROS 2 Python alapú publisher-subscriber beadandó feladat.

## Node-ok leírása
- **publisher_node**: Véletlenszerű lebegőpontos értékeket publikál a `random_topic` nevű topicra.
- **subscriber_node**: Feliratkozik a `random_topic`-ra, és konzolra logolja a kapott üzeneteket.
